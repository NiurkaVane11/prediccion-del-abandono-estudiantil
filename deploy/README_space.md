# API de Predicción de Deserción Estudiantil

Red neuronal (Keras) que predice el riesgo de abandono de un estudiante universitario, servida con FastAPI.

- Documentación interactiva: `/docs`
- Salud: `GET /salud`
- Predicción: `POST /predecir` (requiere header `X-API-Key`)

Código fuente y CI/CD: https://github.com/NiurkaVane11/prediccion-del-abandono-estudiantil
